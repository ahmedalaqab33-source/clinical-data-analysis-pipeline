# Reproducibility checklist

- [ ] Record the protocol and analysis-plan version.
- [ ] Record the Python version and dependency installation output.
- [ ] Verify ethics approval and data-use permissions.
- [ ] Keep raw data outside Git and preserve a read-only source copy.
- [ ] Define variables, units, permissible values, and missing-value codes.
- [ ] Verify expected sample size, time window, and outcome counts.
- [ ] Run `pytest` before analysis.
- [ ] Run the pipeline with an explicit input path.
- [ ] Retain the quality-control JSON with the controlled analysis record.
- [ ] Review generated outputs for disclosure risk.
- [ ] Record deviations from the prespecified analysis.
