# Support

## Intended use

This repository is a reproducible research-software example for tabular clinical-research data quality checks and descriptive summaries. It is not a validated clinical decision system, diagnostic tool, or production clinical application.

## Questions and reproducible bug reports

For technical questions or reproducible defects, please open a GitHub issue using the available issue templates. Include:

- operating system;
- Python version;
- relevant package versions;
- the exact command run;
- the full non-sensitive error message;
- the smallest synthetic example that reproduces the problem.

Do not upload patient-level, identifiable, confidential, proprietary, or institutionally restricted data.

## Methodological changes

Requests that alter statistical methods, variable definitions, inclusion criteria, estimands, missing-data handling, or interpretation should explain the scientific rationale and expected analytical impact.

## Security and privacy

Potential security or privacy concerns should follow the instructions in `SECURITY.md` and should not be disclosed publicly when doing so could expose sensitive information.
