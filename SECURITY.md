# Security and data privacy

## Supported version

Only the current default branch is maintained.

## Report a concern

For suspected credential exposure, sensitive-data disclosure, or a security vulnerability, contact **ahmedalaqab33@gmail.com** privately. Do not place sensitive details in a public issue.

## Data policy

This repository must not contain participant identifiers, medical-record numbers, contact details, credentials, raw hospital/EHR/claims data, or restricted clinical datasets. Generated outputs must be reviewed for disclosure risk before publication.

Revocation or rotation of exposed credentials should occur immediately through the relevant service; removing a file from the latest commit alone does not remove it from Git history.
