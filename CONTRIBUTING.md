# Contributing

Thank you for considering a contribution.

## Principles

Contributions must preserve scientific transparency, data privacy, and the repository's limited descriptive scope. Do not submit clinical or participant-level data, credentials, unpublished manuscripts, or institutionally restricted material.

## Workflow

1. Open an issue describing the proposed scientific or technical change.
2. Create a focused branch.
3. Add or update tests and documentation.
4. Run `python -m ruff check .` and `python -m pytest`.
5. Submit a pull request explaining the rationale, validation, and any analytical implications.

Changes that alter variable definitions, statistical methods, estimands, inclusion criteria, or interpretation must be justified scientifically and documented as protocol or analysis-plan changes.
